# คัดเบอร์

เว็บสำหรับอ่านเบอร์โทรจากไฟล์ `.txt` ตัดเบอร์ซ้ำ แล้วแบ่งเป็นไฟล์ใหม่ตามจำนวนที่กำหนด โปรแกรมรันบนเครื่องตัวเอง และไม่ส่งรายการเบอร์ออกไปไหน

## ใช้ทำอะไร

- เลือกโฟลเดอร์โปรเจกต์จาก Finder หรือเปิดโฟลเดอร์ในเครื่อง
- อ่านเบอร์มือถือไทย 10 หลักที่ขึ้นต้น 06, 08, 09 รวมรูปแบบ `081-234-5678` และ `+66`
- เก็บเบอร์แรกที่เจอ แล้วตัดตัวที่ซ้ำ
- ตั้งชื่อไฟล์ใหม่แบบ `num_001.txt` และเลือกจำนวนสูงสุดต่อไฟล์ได้ (ค่าเริ่มต้น 40,000)
- บันทึกแต่ละครั้งแยกโฟลเดอร์ตามวัน-เดือน-ปีและเวลา เช่น `num_out/23-10-2026_19-36-22/` ชื่อไฟล์กับเลขลำดับซ้ำกันได้โดยไม่ทับชุดเก่า

ไฟล์ต้นทางไม่ถูกแก้ไข

## วิธีรัน

ต้องมี Node.js

```bash
cd app
npm install
npm start
```

เปิด [http://127.0.0.1:4173](http://127.0.0.1:4173)

## ใช้บนเว็บ

เปิด [https://phone-cut.vercel.app/](https://phone-cut.vercel.app/) แล้วเลือกโฟลเดอร์จากเครื่อง การคัดเบอร์เกิดในเบราว์เซอร์ เบอร์ไม่ถูกอัปโหลด ถ้าเบราว์เซอร์เขียนไฟล์กลับเข้าโฟลเดอร์ไม่ได้ ระบบจะให้ดาวน์โหลดเป็นไฟล์ zip

## เทส

```bash
cd app
npm test
```

โฟลเดอร์ `app/sample-project` มีไฟล์ตัวอย่างสำหรับลองคัดเบอร์

## สิ่งที่ไม่อยู่ใน git

รายการเบอร์ที่คัดแล้วและไฟล์ผลลัพธ์อยู่บนเครื่องเท่านั้น เช่น `num_*.txt`, `output_part*.txt` และ `app/sample-project/num_out/`
